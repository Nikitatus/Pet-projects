# Machine Learning Pet-Projects

A collection of machine learning projects and smaller research experiments.

## Projects

| Project | Description |
| --- | --- |
| [Sentiment classifier](projects/sentiment-classifier/) | Tweet sentiment classification comparing a custom BiLSTM and pretrained transformer models. |
| [Image upscaling](projects/upscaling-research/) | Evaluation and comparison of image super-resolution models. |
| [CycleGAN](projects/cyclegan/) | Unpaired image-to-image style transfer with CycleGAN. |

## Experiments

| Experiment | Description |
| --- | --- |
| [RLHF for movie reviews](experiments/rlhf-movie-reviews/) | Reward modeling and PPO fine-tuning for movie-review generation. |
| [Model quantization](experiments/quantization/) | Post-training quantization experiments, including GPTQ and custom CUDA kernels. |

Each directory is self-contained, setup and usage instructions live in the directory's folder.
